# Code of Conduct

We want a welcoming, respectful project for everyone. Treat other contributors with patience and courtesy. Disagreement about code is welcome; personal attacks, harassment, discriminatory language, and unwanted attention are not.

Maintainers may edit or remove harmful content and may restrict participation when needed to protect the community. Report conduct concerns privately to the repository maintainers through GitHub, rather than posting personal details in a public issue. Reports will be reviewed confidentially where practical. Maintainers will explain decisions to the people involved when it is safe to do so.
