# Changelog

All notable changes are documented here. This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-06

### Added

- Korean-token parser with Unicode source positions and nested loop validation.
- Bounded, wrapping byte-tape VM with byte input and output.
- `hachimi run`, `eval`, and `check` commands, plus help and version output.
- Greeting example, bilingual documentation, tests, and cross-platform CI.
