# Security Policy

## Supported versions

The current `0.1.x` release line receives security fixes as maintainers are able to provide them. Older versions are unsupported.

## Reporting a vulnerability

Please use the repository's GitHub private vulnerability reporting or a private security advisory to contact maintainers. Avoid public issues for exploitable details. Include the affected version, a minimal reproducer, and impact. Maintainers will acknowledge and triage reports as soon as practical, coordinate a fix, and credit reporters if they wish.

The VM limits execution steps and tape cells by default. Those limits do not replace resource controls when running untrusted programs in a larger service.
